# Project naming convention

For future code and dialogue, use the approved in-game names from
[Docs/ParodyTranslationDictionary.md](Docs/ParodyTranslationDictionary.md).
Use those names in player-facing text, narrative data, and identifiers referring
to the listed locations, factions, and characters. Adapt spacing to the language's
identifier conventions without changing the approved name.

Keep real-world lookup names in the editorial dictionary only. Do not introduce
them into gameplay or dialogue. The dictionary is a naming convention, not a
legal clearance determination.
